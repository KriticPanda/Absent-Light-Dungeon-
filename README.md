-ABOUT THE GAME

Absent Light Dungeon is a game where you are an adventure trying to collect gold from a dungeon,
you move using the directional arrow keys to do so while dodging goblins, if a goblin gets you,
it's game over.

-THE DEVELOPMENT PROCESS

The development process for me was an oportunity to learn what was taught in our previous module,
I took the example used in class and built upon it, to give vision to what I wanted, a simple
game, with simple mechanics.
I used HTML, CSS and Javascript to make this game come true, with the main tool being DOM manipulation.

-AI USED ON THIS PROJECT

AI was invaluable on creating the assests, from the backgrounds to the animation of the sprites to make the game feel more
"lively", this made the progress much smoother and fluid.
I used agents also to consult syntax errors and sometimes logical ones of things previously shown, but most of what I implemented, was me just observing methods taught in class. One example is the gold added to the game, I new already I had to
create a gold class, create an interval in which it spawns and a random position generator from the enemy class, then give it
a collision behaviour so instead of dying, it would give me a set amount of "gold" each time the player collides with it or
if collided with the enemy it would remmove it from the game. I did ask AI to help me with the removal of it at the start of the game.

AI also help me find the method used to play audio files and to give me an explanation of how it works, then I implemented it myself with that starting logic.
